# AI Writing Studio

AI 驱动的 Markdown 写作助手，支持多种 AI 模式，完全免费，无需 API Key。

## 功能特点

- **Markdown 编辑器** - 实时预览，语法高亮
- **AI 写作模式** - 润色/扩写/缩写/翻译/总结/续写
- **文档管理** - 本地存储，自动保存
- **暗色主题** - 舒适写作体验
- **流式输出** - AI 实时生成

## 技术栈

- React 18
- Tailwind CSS
- CodeMirror 5
- Puter.js (免费 AI API)
- Marked.js

## 使用方法

1. 直接打开 `index.html` 即可使用
2. 在左侧编辑器编写 Markdown
3. 右侧实时预览
4. 选中文本，点击 AI 按钮进行处理

## AI 功能

使用 Puter.js 提供的免费 AI API，支持 400+ 模型，无需任何 API Key。

## 部署

### Vercel

1. 推送到 GitHub
2. 在 Vercel 导入项目
3. 自动部署

### 本地运行

直接打开 `index.html` 即可，无需安装任何依赖。
